# P6 - Inatel

Anotações do **6º período** da graduação no [Inatel](https://inatel.br), organizadas como um vault do [Obsidian](https://obsidian.md).

As notas são escritas em Markdown, com fórmulas em LaTeX e alguns diagramas feitos no Excalidraw.

## Disciplinas

### 🏛️ [Arquitetura de Software](Arquitetura%20de%20Software)
- Conceitos de Arquitetura de Software
- Propriedades e Princípios de Software
- Princípios SOLID e Lei de Demeter
- Padrões de Projeto
- UML
- Comentários das apresentações e estudo para prova

### 🔢 [Cálculo Numérico](C%C3%A1lculo%20Num%C3%A9rico)
- Interpolação e Extrapolação
- Ajuste de Curvas: Método dos Mínimos Quadrados e casos não lineares
- Integração Numérica
- Teste de Hipóteses
- Testes de Normalidade
- Resumo para prova

### ⚙️ [Engenharia de Software](Engenharia%20de%20Software)
- Introdução e aulas iniciais
- Métodos Ágeis
- Teste de Software, Teste de Unidade e Teste com Mocks
- TDD (Test Driven Development)
- DevOps: Integração, Entrega e Deployment Contínuos
- Diagramas UML (Excalidraw)
- Resumo para prova

### 🌐 [Redes](Redes)
- Endereçamento IPv4, sub-redes e VLSM
- Protocolos IP e ICMP
- Camada de Transporte
- Conceitos de Cibersegurança
- Atividades (WLANs e roteadores no Packet Tracer)
- Estudos do livro e resumo para prova

## Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/F-Loschi/P6-Inatel.git
   ```
2. No Obsidian, escolha **Abrir pasta como vault** e selecione a pasta `P6-Inatel`.

As configurações do vault (tema e plugins) estão em `.obsidian/`. Os plugins usados são:

- [Excalidraw](https://github.com/zsviczian/obsidian-excalidraw-plugin): diagramas desenhados à mão
- [LaTeX Suite](https://github.com/artisticat1/obsidian-latex-suite): atalhos para escrever fórmulas
- [Style Settings](https://github.com/mgmeyers/obsidian-style-settings): ajustes visuais do tema

As notas também podem ser lidas direto no GitHub, mas os desenhos do Excalidraw e os links internos (`[[...]]`) só aparecem corretamente no Obsidian.

## Estrutura

```
P6-Inatel/
├── Arquitetura de Software/
├── Cálculo Numérico/
├── Engenharia de Software/
├── Redes/
```
