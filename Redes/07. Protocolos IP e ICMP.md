## Protocolo IPv4
- RFC 791
- Define um mecanismo de transmissão de pacotes do tipo "melhor esforço"
	- "vou tentar entregar o pacote, mas não garanto nada"
- Trabalha no modo "não orientado à conexão" e "não confiável"
- Possibilita o encaminhamento de diferentes tipos de tráfego
	- Permite o encapsulamento de diferentes protocolos(camadas 3 e 4)
- Pode ser transportado por diferentes padrões de redes
	- Permite ser encapsulado em diferentes protocolos de camada 2
## Datagrama IPv4
![[Pasted image 20251008175603.png]]
- Versão(4 bits): versão do protocolo IP. (versão = 4)
- HLEN(4 bits): comprimento do cabeçalho dados em valores de 32 bits(4 bytes)
	- Mínimo(sem opções): 5(20 bytes) - Máximo(com opções) = 15(60 bytes)
- Tipo de serviço(8 bits): indica o tratamento (prioridade) dado ao datagrama IP durante sua transmissão, sendo usado na configuração de QoS
	- Redefinido pelo IETF como "Serviços Diferenciados"
- Comprimento Total(16 bits): comprimento do datagrama(cabeçalho + dados), dado em bytes
- Identificação(16 bits): número designado pelo remetente para ajudar na remontagem de um datagrama fragmentado
- Flags(3 bits): dois últimos bits usados no controle de fragmentação
- Deslocamento do Fragmento(16 bits): é o número de partes de 64 bits(8 bytes) sem contar o cabeçalho, que estão contidos em fragmentos anteriores
- Tempo de Vida(TTL)(8 bits): indica o número máximo de saltos permitidos ao datagrama. A cada roteador, este campo é decrementado de "1"; quando se iguala a "0", o datagrama é descartado pelo roteador.
- Número do Protocolo(8 bits) indica o protocolo encapsulado no campo dados(carga útil) do datagrama IP
	- Exemplos: ICMP - 01; IGMP - 02
- Check-Sum do cabeçalho(16 bits): valor resultante de uma soma de verificação ocorrida no cabeçalho do datagrama, permitindo detectar possíveis erros no cabeçalho do datagrama recebido
- Endereço IP de Origem(32 bits): endereço IP do host que envia(origem) o datagrama
- Endereço IP de destino(32 bits): endereço IP do host de destino do datagrama
- Opções(n bits): campo opcional que pode ser utilizado para funções de testes de rede e depuração
	- Exemplos: Record Route(Armazenamento de Rota), Strict Source Route(Roteamento Restrito da Origem)
- Data(payload): utilizado para transporte de outros protocolos; a carga útil do datagrama IP
## Protocolo IPv6
### Principais características:
- 128 bits para endereçamento
- Cabeçalho base simplificado
- Cabeçalhos de extensão
- Identificação de fluxo de dados(QoS)
- Realiza a fragmentação e remontagem dos pacotes apenas na origem e no destino
- Não requer o uso de NAT, permitindo conexões verdadeiramente fim-a-fim
- Mecanismos de IPSec incorporados ao protcolo
- etc
## Cabeçalho IPv4 x Cabeçalho IPv6
### Cabeçalho IPv4:
- São 12 campos ficos
- Pode ou não conter opções
- Tamanho total pode variar entre 20 e 60 octetos
### Cabeçalho IPv6:
- Maior simplicidade:
	- São apenas 8 campos fixos
	- Tamanho fixo: 40 octetos
- Maior flexibilidade
	- Diversas funcionalidades implementadas por meio de cabeçalhos de extensão
- Maior eficiência:
	- Reduz o tempo de processamento dos pacotes
