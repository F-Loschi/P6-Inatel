## MVC(Model View Controller):
- O que era feito na Web 1.0 não servia mais para a Web 2.0 e o que era feito na Web 2.0 não servia pra Web 3.0
- ### Model(Lógica de Negócio)
	- Subdividido em Service(regras de negócio) e Entity(classes de dados)
- ### View(Lógica de Apresentação)
- ### Controller(Orquestrador)
- View realiza requisição, controller invoca o método de negócio e com a resposta do model, renderiza uma nova view
- Model faz comunicação direta com o banco de dados, view é jogada na web e a web faz requisições para o controller
## SOA(Service Oriented Architecture):
- As requisições feitas para o SOA são feitas com Json para ser auto-compreensíveis, simples e de manutenção facilitada
