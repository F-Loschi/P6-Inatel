## Inferência Estatística
- Fazer afirmações sobre uma amostra de uma população
- Hipótese: pressuposição
- Verificação: teste de hipóteses
- Conclusão: Veracidade ou não
- H0: Hipótese de nulidade, média do grupo A = média do grupo B
- H1: Hipótese alternativa, média do grupo A != média do grupo B
